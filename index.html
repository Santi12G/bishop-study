1.1 Fundamentos

1.1.1 Datos, características y etiquetas

Un patrón x contiene características; su etiqueta t indica la respuesta esperada. El conjunto supervisado está formado por pares (x, t).

1.1.2 Clasificación y regresión

Clasificación predice categorías; regresión predice valores continuos.

1.1.3 Evaluación

Entrenamiento ajusta parámetros, validación elige configuraciones y prueba estima el desempeño final.

1.1.4 Generalización

Un modelo útil funciona con datos nuevos; overfitting memoriza y underfitting simplifica demasiado.

Ejemplo: usa 70% de datos para entrenar, 15% para elegir hiperparámetros y 15% para medir generalización una sola vez.

01Bishop 3

Linear Models

Usan una combinación ponderada de las entradas para separar clases o predecir un valor.

Ejemplo: clasificar flores con y = w₁·largo + w₂·ancho + w₀. Si y ≥ 0, clase A; si y < 0, clase B.

Relacionado con: discriminantes lineales, logística, mínimos cuadrados, Fisher y perceptrón.

02Contexto

KNN

Clasifica un dato según las etiquetas de sus k vecinos más cercanos. No aprende una frontera paramétrica explícita.

Ejemplo: para una flor nueva, sus 3 vecinos son A, A y B; KNN predice la clase A.

Complemento del mapa de aprendizaje supervisado.

03Contexto

Decision Trees

Dividen el espacio mediante preguntas sucesivas sobre las características hasta llegar a una predicción.

Ejemplo: ¿peso > 10 kg? → ¿color rojo? → clasificar una fruta como manzana o naranja.

Las hojas representan regiones de decisión; a diferencia del perceptrón, sus fronteras son cortes por reglas.

04Contexto

Naive Bayes

Calcula la probabilidad de cada clase usando Bayes y supone independencia condicional entre las características.

Ejemplo: en un correo con “premio” y “gratis”, comparar P(spam|palabras) con P(no spam|palabras).

Relacionado conceptualmente con las probabilidades posteriores de la discriminación logística y las entradas Bernoulli.

05Bishop 3–4

Neural Networks

Aprenden pesos y, en el caso multicapa, representaciones internas no lineales mediante unidades ocultas.

Ejemplo: una red con una capa oculta aprende XOR, que un discriminante lineal no puede separar.

Tema central de esta página: perceptrón, MLP, activaciones, retropropagación y Hessiana.

06Contexto

SVM

Busca una frontera con margen máximo entre clases y puede usar funciones kernel para fronteras no lineales.

Ejemplo: elegir la línea que deja la mayor distancia posible a los puntos más cercanos de cada clase.

Comparte con Fisher y los discriminantes la idea geométrica de separar clases mediante fronteras.

Supervised model 01

Linear Models

01

Los modelos lineales convierten cada característica en una contribución ponderada. Son la primera herramienta para entender clasificación, regresión y fronteras de decisión.

1.2.1–1.2.5 Conceptos y procedimiento

HabilidadTraducir un problema a una ecuación, interpretar los pesos y decidir si una frontera lineal es suficiente.
Cuándo usarloCuando la relación es aproximadamente lineal, se necesita explicar la decisión o se requiere un modelo rápido.

1.2.2 Clasificación logística

y = wᵀx + w₀

Si y ≥ 0 se predice C₁; si y < 0, C₂. La sigmoide transforma el resultado en una probabilidad:

P(C₁|x) = 1 / (1 + e−y)

1.2.1 Regresión lineal

ŷ = w₀ + w₁x₁ + ··· + wdxd

Los pesos indican cuánto cambia la salida cuando una característica aumenta una unidad, manteniendo las demás constantes.

1.2.4 Pesos, sesgo y pérdida · Ejemplo superior

Resuelto

Usamos ingreso normalizado x₁ = 0.8, historial x₂ = 0.6, w = (2, 1) y w₀ = −1.5.

y = 2(0.8) + 1(0.6) − 1.5 = 0.7

Como y > 0, el modelo clasifica como “aprobar”. La probabilidad logística es aproximadamente 0.668. El ingreso tiene el doble de influencia que el historial porque su peso es mayor.

  1. Normaliza las características.
  2. Calcula el producto peso-entrada y suma el sesgo.
  3. Aplica umbral o sigmoide.
  4. Interpreta los pesos y revisa errores.

Reto de dominio

Construye un clasificador para una planta con x₁ = longitud y x₂ = ancho. Elige pesos, calcula la frontera y explica qué característica domina. Después prueba qué ocurre al cambiar w₀.

Supervised model 02

KNN · K-Nearest Neighbors

02

KNN clasifica usando la proximidad: guarda los datos etiquetados y consulta los k ejemplos más cercanos cuando llega un patrón nuevo.

1.3.1–1.3.5 Conceptos y procedimiento

HabilidadCalcular distancias, elegir k, votar y detectar cuándo una escala desigual distorsiona el resultado.
Decisionesk pequeño captura detalles pero es sensible al ruido; k grande suaviza pero puede borrar fronteras locales.

1.3.1 Distancias y procedimiento

  1. Normaliza las variables.
  2. Calcula la distancia al nuevo punto, normalmente euclídea.
  3. Ordena las distancias y conserva los k vecinos.
  4. Vota la clase mayoritaria o promedia sus valores en regresión.
d(x,z) = √Σᵢ(xᵢ − zᵢ)²

1.3.2 Vecinos · Ejemplo superior

k = 5

Para una flor nueva x = (5.1, 3.5), las distancias a los ejemplos más cercanos son:

40.36A

El voto es A = 3 y B = 2; por tanto KNN predice A. Si la longitud estuviera en centímetros y el ancho en milímetros, primero habría que normalizar.

Supervised model 03

Decision Trees

03

Un árbol divide el espacio con preguntas. Cada nodo elige una característica y un umbral; cada hoja entrega una clase o un valor.

1.4.1–1.4.5 Conceptos y procedimiento

HabilidadConvertir datos en reglas, leer una ruta de decisión y controlar profundidad para evitar sobreajuste.
CriterioUna división es buena cuando deja grupos más puros. Se puede medir con entropía o índice Gini.

1.4.3 Entropía

H(S) = −Σc p(c) log₂ p(c)

Vale 0 cuando todos los ejemplos pertenecen a una sola clase. La ganancia de información compara la impureza antes y después de dividir.

1.4.5 Índice Gini y poda

Gini(S) = 1 − Σcp(c)²

También busca nodos puros. El árbol escoge el umbral que más reduce la impureza.

1.4.2 División · Ejemplo superior: aprobar una solicitud

Ruta interpretable

El árbol aprende:

Ingreso > 2.000
Sí
¿Historial bueno?
Sí → aprobar
No → revisar
No
rechazar

Para una persona con ingreso 2.500 e historial bueno, seguimos “Sí → Sí” y predecimos aprobar. La explicación es una ruta, no una ecuación global.

Supervised model 04

Naive Bayes

04

Naive Bayes combina la probabilidad de una clase con la evidencia observada. Su supuesto “naive” considera independientes las características una vez conocida la clase.

1.5.1–1.5.4 Conceptos y procedimiento

HabilidadConstruir probabilidades a partir de frecuencias, aplicar Bayes y comparar puntuaciones de clases.
PrecauciónLas probabilidades cero requieren suavizado de Laplace; la independencia es una aproximación, no una verdad universal.

1.5.1 Regla de Bayes y posterior

P(C|x) ∝ P(C) ∏ᵢP(xᵢ|C)

Se calcula una puntuación por clase y se elige la mayor. El factor de evidencia P(x) es común a todas las clases y puede omitirse al comparar.

1.5.4 Decisión · Ejemplo superior: detectar spam

Bernoulli

Supón P(spam) = 0.4, P(no spam) = 0.6. Para las palabras “gratis” y “premio”:

Spam: 0.4 × 0.8 × 0.7 = 0.224
No spam: 0.6 × 0.1 × 0.05 = 0.003

Como 0.224 > 0.003, clasificamos el correo como spam. Normalizando, P(spam|x) ≈ 0.987.

  1. Estima el prior de cada clase.
  2. Estima la probabilidad de cada característica por clase.
  3. Multiplica y compara.
  4. Aplica Laplace si alguna frecuencia es cero.

1.5.3 Variantes y Laplace · Reto de dominio

Calcula las puntuaciones de “urgente” y “reunión” para spam/no spam. Explica qué supuesto de independencia estás haciendo.

Supervised model 06

Support Vector Machines

06

SVM busca el hiperplano que separa las clases con el margen más amplio. Los puntos que tocan el margen son los vectores soporte y determinan la frontera.

1.7.1–1.7.4 Conceptos y procedimiento

HabilidadIdentificar la frontera, razonar con margen y distinguir separación lineal de separación mediante kernel.
Idea geométricaUna frontera robusta no solo clasifica: deja la mayor distancia posible a los ejemplos más cercanos.

1.7.2 Margen y vectores soporte

margen = 2 / ‖w‖

Para etiquetas t ∈ {−1,+1}, la condición ideal es t(wᵀx + b) ≥ 1. Los ejemplos con igualdad son los que fijan el margen.

1.7.4 Kernels · Ejemplo superior: elegir una frontera

Máximo margen

Dos posibles líneas separan correctamente dos clases. La línea A deja 0.4 unidades al punto más cercano; la línea B deja 0.9. SVM elige B, aunque ambas tengan cero errores de entrenamiento.

A: margen 0.4
B: margen 0.9 → elegir B

Si los datos no son linealmente separables, un kernel transforma implícitamente el espacio para construir una frontera no lineal.

1.7.3 Regularización · Reto de dominio

Explica por qué una frontera con cero errores puede ser peor que otra con el mismo error pero mayor margen. Relaciona tu respuesta con generalización y ruido.

Módulo 1

Redes de una capa

01

Una única capa de pesos adaptativos transforma las entradas en decisiones de clase. La frontera puede ser lineal en el espacio original o no lineal después de aplicar funciones base.

Discriminantes lineales

Para dos clases, la función discriminante es:

y(x) = wᵀx + w₀
  • La frontera y(x) = 0 es un hiperplano de dimensión d − 1.
  • w define la orientación y w₀ controla el desplazamiento.
  • La distancia orientada al origen es l = −w₀ / ‖w‖.

Multiclase y logística

yₖ(x) = wₖᵀx + wₖ₀

Se elige la clase k cuando su discriminante supera al de todas las demás clases. Las regiones resultantes son convexas.

g(a) = 1 / (1 + e−a)

La sigmoide permite interpretar la salida como una probabilidad posterior.

Representación con sesgo

Se añade la entrada ficticia x₀ = 1 para incorporar el sesgo al vector de pesos:

x̃ = (1, x),   w̃ = (w₀, w),   y(x) = w̃ᵀx̃

Entradas binarias

Un patrón binario puede modelarse con una distribución de Bernoulli:

p(x|Cₖ) = ∏ μₖᵢxᵢ(1 − μₖᵢ)1−xᵢ

Separabilidad y extensiones

Conceptos clave

Separabilidad lineal

Existe un hiperplano que clasifica correctamente el 100% de los patrones de entrenamiento.

XOR

Los cuatro puntos XOR no pueden separarse con una sola línea. Es el límite clásico de un discriminante lineal.

Funciones base

Con φ(x), la frontera puede ser no lineal en x, aunque continúa siendo lineal en el espacio transformado.

Teorema de Cover

Probabilidad de separabilidad de N puntos aleatorios en d dimensiones.

F(N,d) = 0.5000

Teorema de Cover: casos límite

Para examen

Para N ≤ d + 1, todas las dicotomías están separadas linealmente y F(N,d) = 1. Cuando N = 2(d + 1), la fracción es exactamente 0.5.

El problema XOR es el caso mínimo que muestra que una red de una sola capa no puede representar todas las asignaciones de clase. En dimensiones superiores, la misma dificultad aparece como problema de paridad.

Módulo 2

Optimización de pesos

02

Mínimos cuadrados

Se minimiza el error cuadrático entre la salida y los objetivos:

E(w) = ½ ΣₙΣₖ (yₖ(xⁿ) − tₖⁿ)²

La solución es la proyección ortogonal de T sobre el subespacio generado por Φ.

Wᵀ = Φ†T

Estabilidad: usa SVD cuando ΦᵀΦ sea singular o N < M. Evita pesos enormes y cancelación numérica.

Regla delta

Para una red lineal, el descenso de gradiente estocástico actualiza:

Δwₖⱼ = η(tₖⁿ − yₖⁿ)φⱼⁿ

Con una activación no lineal se incluye la derivada de la activación:

Δw ∝ (t − y)g′(a)φ

Discriminante lineal de Fisher

Busca una proyección con gran separación entre clases y poca dispersión dentro de cada clase.

Entre clases
SB
Dentro de clases
SW
Criterio
J(w) = wᵀSBw / wᵀSWw

En dos clases, la dirección óptima es w ∝ SW−1(m₂ − m₁). Para c clases, Fisher extrae como máximo c − 1 características.

Dos clases

SW = ΣC₁(x−m₁)(x−m₁)ᵀ + ΣC₂(x−m₂)(x−m₂)ᵀ
SB = (m₂−m₁)(m₂−m₁)ᵀ

Varias clases

J(W) = Tr{(WSWWᵀ)−1(WSBWᵀ)}

El rango máximo de SB es c − 1, así que ese es el límite de dimensiones discriminantes.

Con objetivos alternos t = N/N₁ para C₁ y t = −N/N₂ para C₂, mínimos cuadrados produce la misma dirección de pesos que Fisher.

J(w) ≈ 18.00

Módulo 3

El perceptrón clásico

03

Rosenblatt y Heaviside

El perceptrón combina funciones base fijas con una activación de umbral. No minimiza el error cuadrático: optimiza un criterio sobre los patrones mal clasificados.

Eperc(w) = −Σφⁿ∈M wᵀ(φⁿtⁿ)

Teorema de convergencia

Si los datos son linealmente separables, el algoritmo encuentra una solución en un número finito de actualizaciones. En datos no separables, no existe una frontera perfecta y el entrenamiento no converge a cero.

Simulador de actualización

Presenta un patrón y observa cómo cambia el vector de pesos. La etiqueta usa +1 para C₁ y −1 para C₂.

Salida: 1 · correctow = [0.00, 0.00, 0.00]

Convergencia y algoritmo pocket

La regla de Rosenblatt converge en un número finito de pasos únicamente cuando existe un hiperplano que separa los datos. Con datos no separables, como XOR, los pesos oscilan indefinidamente.

El algoritmo pocket conserva la mejor solución encontrada para trabajar con datos no separables, aunque no crea una separación perfecta.

Limitaciones de Minsky y Papert

Con características locales fijas, un perceptrón no puede resolver problemas de paridad ni decidir si una forma topológica está simplemente conectada o desconectada.

La salida natural es permitir que las características se adapten durante el aprendizaje: aparecen las redes multicapa.

Ejemplo resuelto: actualización del perceptrón

Con w = (0,0,0), η = 1, entrada aumentada x̃ = (1, 0.5, 0.5) y objetivo t = +1, el patrón se clasifica erróneamente si el empate se asigna a C₂.

wnuevo = wviejo + ηx̃t = (0,0,0) + (1,0.5,0.5) = (1,0.5,0.5)

4.1 Mapeos feed-forward

Capas adaptativas

Una red feed-forward no contiene ciclos: la información fluye desde la entrada hacia la salida. Las unidades intermedias son unidades ocultas y sus parámetros sí se adaptan durante el entrenamiento.

aj = Σiw(1)jixi + w(1)j0;   zj = g(aj)
yk = ĝ(Σjw(2)kjzj + w(2)k0)

Las topologías generales pueden incluir conexiones que saltan capas. Los diagramas de Hinton representan el signo del peso con el color y su magnitud con el tamaño.

4.2 Unidades de umbral

Geometría

Entradas binarias

Con entradas 0/1 se computan funciones booleanas. Una unidad oculta por patrón puede memorizar cualquier función, pero puede requerir hasta 2d unidades y no generaliza.

Una capa

Sin unidades ocultas, solo se forman fronteras de decisión dadas por hiperplanos.

Dos capas

Una capa oculta y una salida pueden combinar hiperplanos con AND para delimitar regiones convexas cerradas.

Tres capas: dos capas ocultas permiten combinar regiones convexas con OR; así se forman regiones no convexas y múltiples regiones disjuntas.

Ejemplo resuelto: triángulo con AND

Tres unidades ocultas trazan los límites izquierdo, derecho e inferior. Cada una produce 1 cuando el punto está del lado correcto. La salida exige las tres activaciones simultáneamente: es una operación AND que delimita el triángulo.

1.6.3.1 Sigmoid

Activaciones diferenciables

Las funciones de umbral discontinuas se sustituyen por activaciones continuas y diferenciables para poder entrenar mediante derivadas y retropropagación.

Logística

g(a) = 1 / (1 + e−a)

Su salida está en el intervalo (0, 1).

1.6.3.2 Tanh

g(a) = tanh(a) = (ea − e−a) / (ea + e−a)

Su salida es simétrica y está entre −1 y 1.

1.6.3.3 ReLU

g(a) = max(0, a)

Anula valores negativos y conserva los positivos; suele facilitar el entrenamiento de redes profundas.

La derivada puede expresarse usando la propia salida de la unidad, simplificando el cálculo del gradiente.

4.4 Simetrías en el espacio de pesos

Equivalencia funcional

Distintas configuraciones de pesos pueden producir exactamente el mismo mapeo entrada-salida.

Permutación

Intercambiar dos unidades ocultas y reordenar sus conexiones de salida no cambia la función. Con M unidades existen M! permutaciones equivalentes.

Inversión de signos

Con activaciones simétricas como tanh, cambiar los signos de los pesos de entrada y salida de una unidad puede conservar la función.

Consecuencia

El espacio de error contiene múltiples mínimos globales equivalentes. La predicción no cambia, aunque el análisis de pesos se complique.

4.5 Redes de orden superior

Productos cruzados

Introducen interacciones entre variables para representar invariancias complejas, como rotaciones o escalas, sin depender necesariamente de una red profunda.

y(x) = w₀ + Σᵢwᵢxᵢ + Σᵢⱼwᵢⱼxᵢxⱼ

Al transformar explícitamente el espacio de entrada con términos de segundo orden, una sola capa adaptativa puede resolver problemas no lineales como XOR.

4.6 Regresión projection pursuit

Regresión no paramétrica

Proyecta los datos multidimensionales sobre direcciones wᵀx y aplica funciones no lineales unidimensionales para aproximar funciones complejas de forma aditiva.

La conexión con el MLP muestra que una red feed-forward con una capa oculta puede interpretarse como un modelo de regresión no paramétrica aditiva.

4.7 Teorema de Kolmogorov

Representación universal

El teorema de superposición establece que toda función continua multivariable puede representarse exactamente con una red de dos capas ocultas y un número fijo de unidades, 2d + 1, para una entrada de dimensión d.

Advertencia práctica: las funciones de Kolmogorov pueden ser muy poco suaves. Las redes estándar suelen aproximar funciones usando activaciones sigmoidales.

4.8 Retropropagación de errores

Back-propagation

Forward pass

Las entradas atraviesan la red capa por capa hasta calcular la salida y el error.

Backward pass

La regla de la cadena propaga el error hacia atrás y calcula las deltas δ de las unidades.

Actualización

Los pesos se mueven en dirección opuesta al gradiente usando la tasa de aprendizaje η.

Δw = −η ∂E/∂w

4.9 Matriz Jacobiana

Primer orden

Contiene las derivadas parciales de las salidas de la red con respecto a las variables de entrada.

Jki = ∂yk / ∂xi

Permite estudiar sensibilidad, control óptimo y cambios en la salida ante pequeñas perturbaciones de la entrada.

4.10 Matriz Hessiana

Segundo orden

Es la matriz de derivadas de segundo orden del error respecto a los pesos.

Hij = ∂²E / (∂wi∂wj)

Describe la curvatura local, ayuda a identificar mínimos locales y se usa en Levenberg–Marquardt y métodos quasi-Newton.

Conexión de los temas avanzados

Las unidades sigmoidales hacen posible la retropropagación; la Jacobiana describe sensibilidad de primer orden y la Hessiana aporta curvatura de segundo orden. Las simetrías explican por qué diferentes pesos pueden representar la misma función.
